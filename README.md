# 就活ボード ― 新卒就活・選考進捗管理アプリ（28卒 / 27卒 / 既卒対応）

> **洗練されたダークグラスモーフィズムUIで、企業研究から内定獲得までを一元管理できる就活コックピット。**  
> サーバー不要・完全オフライン動作・LocalStorage自動保存・ゼロビルド構成。

---

## 🌟 主な機能と特徴

### 1. 🏢 日本取引所グループ（JPX）公認・東証上場＆主要未上場 1,735 社データベース
- **東証公式マスターデータ＆主要名企連携**：
  - **TOPIX Core30 / Large70 / Mid400 / グロース**：トヨタ、ソニー、三菱商事、キーエンス、ファーストリテイリング、NTT、リクルート、日立、メルカリなど日本を代表する主要上場企業群を完全網羅。
  - **外資・国内未上場大手・戦略コンサル・IT**：日本TCS（日本タタ・コンサルタンシー・サービシズ）、マッキンゼー、BCG、ベイン、アクセンチュア、デロイト、PwC、KPMG、EY、フォーティエンス（Fortience/旧クニエ）、サントリー、味の素、各種シンクタンクなど、就活重要企業を完全カバー。
- **実務直結の企業情報**：
  - 証券コード、東証市場区分（プライム/グロース/スタンダード/非上場）、業種大分類・細分業種、企業規模・従業員数。
  - **就職人気企業ランキング格付**：`TOP 100` / `TOP 300` / `TOP 500` / `名門企業` のゴールド＆パープルバッジで視覚化。
  - **スマート5次元ファジー検索**：半角カタカナ（`ﾀﾀ`）、ひらがな（`そにー`）、法人格（`株式会社`の自動無視）、英数字大文字小文字をシームレスに横断検索。
  - **詳細初任給データ**：大卒初任給・大学院卒（修士）初任給を個別集計。
  - **平均年収データ**：各社の平均年収（万円）を完備。
- **「＋ 新規企業を追加」**：未収録のスタートアップや地方優良企業、官公庁・自治体も自由に手動登録可能。

### 2. 📋 劇的スリム化・インタラクティブ選考カンバン
- **選考ステージ**：
  `気になる` → `エントリー` → `ES・Webテスト` → `一次面接` → `二次・最終面接` → `内々定・内定`
- **極小スリムカード**：
  選考中の企業を直感的に俯瞰できるよう、カード内は「公式Logo ＋ 社名 ＋ 直近締切アラート」のみの無駄のない単行設計（高さ約52px）。
- **ドラッグ＆ドロップ**：PCでは直感的なD&Dで進捗ステージを一発更新。

### 3. 🖼️ 1,676 社公式企業ロゴ内蔵（カバー率 96.7%）・完全オフライン表示
- **高解像度ローカルアセット**：主要 1,676 社の公式企業ロゴ/ファビコンを `assets/logos/` にローカル格納。
- **優雅なフォールバック**：ロゴ未登録の企業や通信環境に左右されず、自動的に企業ブランドカラーの頭文字アバターへシームレスに切り替わります。

### 4. 📱 スマホ・Android / iOS モバイルUI完全対応
- **スマホ特化レイアウト**：片手操作に適したボトムシートモーダル、コンパクトヘッダー、横スクロール式チップフィルター。
- **100% レスポンシブ**：画面幅に関わらず横スクロール崩れゼロ、タップしやすい44pxタッチターゲット。

### 5. 📑 選考管理リスト（ソート・行内クイック編集対応）
- **全カラムのクリックソート**：
  企業名、業界・業種、規模・従業員数、平均年収、初任給（大卒・院卒）、選考ステージ、直近締切日順に昇順/降順並び替え可能。
- **行内直接操作**：セレクトボックスから選考ステージを即座に更新。
- **Excel対応CSVエクスポート**：UTF-8 BOM付きCSVを出力するため、Excelやスプレッドシートで文字化けせずに直接閲覧・集計可能。

### 6. 📝 企業選考詳細＆面接復盤モーダル
- **マイページ一元管理**：マイページURL（直接開くボタン付き）、ログインID／受験番号を保存。
- **締切カウントダウン**：日付選択で「本日締切」「明日締切」「あとX日」「期限超過」を自動計算・ハイライト表示。
- **タグ管理**：`早期選考`、`インターン経由`、`リクルーター面談`、`OB訪問済`、`推薦`、`高年収` などのプリセット付きタグ管理。
- **就活ノート機能**：
  - 志望動機・企業研究メモ
  - ES設問・提出テキスト控え
  - 面接ログ・質問内容・逆質問・振り返り

### 7. 📊 データ分析ダッシュボード & 就活TODO
- **選考ファネル通過率**：エントリーからES提出、面接、内定への到達社数と歩留まり率（%）を可視化。
- **業界別分布ドーナツグラフ**：志望業界のポートフォリオ偏りをチェック。
- **直近の選考日程アラート**：締切の迫った企業を時系列で自動リストアップ。
- **就活TODOチェックリスト**：やるべきタスクをチェック＆新規追加可能。

### 8. 💾 データの永続化・バックアップ
- **LocalStorage自動保存**：ページをリロードしても、ブラウザを閉じてもデータは保持されます。
- **JSONバックアップ**：1クリックで全データをファイル保存＆復元可能。
- **卒年切り替え**：ヘッダーのバッジから `28卒`、`27卒`、`26卒`、`29卒`、`既卒・転職` をワンクリック切り替え。

## 🚀 クイックスタート（インストール・環境構築不要）

1. 本リポジトリの `index.html` をダブルクリックして開くか、ブラウザ（Google Chrome / Microsoft Edge / Safari / Firefox）にドラッグ＆ドロップしてください。
2. Node.jsのインストールやサーバーの起動は**一切不要**です。完全オフライン・通信なしで動作します。

## 🔒 プライバシーとセキュリティについて

- 本アプリは**すべてのデータをユーザー端末内のローカルストレージ（LocalStorage）にのみ保存**します。
- 外部サーバーへのデータ送信、トラッキング、広告コードは一切含まれていません。
- 企業の選考状況、志望動機、面接記録など、就活に関わる機密情報は完全にあなたの端末内でのみ保護されます。
